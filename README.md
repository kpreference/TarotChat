# TarotChat

## 소개

TarotChat은 Unity를 기반으로 개발된 타로 상담 애플리케이션입니다.

사용자는 질문을 입력하고 타로 카드를 선택하여 카드의 의미와 해석을 확인할 수 있습니다. 직관적인 UI와 대화형 인터페이스를 통해 쉽고 재미있게 타로 콘텐츠를 즐길 수 있습니다.

## 주요 기능

* 타로 카드 뽑기
* 카드별 의미 및 해석 제공
* 사용자 질문 기반 상담 기능
* 대화형 채팅 인터페이스
* Unity 기반 UI 구현

## 개발 환경

* Unity 6000.0.33f1
* C#
* Unity UI System

## 사용 방법

1. 저장소를 다운로드합니다.
2. Unity Hub에서 프로젝트를 엽니다.
3. 프로젝트를 실행합니다.
4. 질문을 입력하고 타로 카드를 선택하여 결과를 확인합니다.

## 프로젝트 구조

```text
Assets/
├── Scripts/
├── Scenes/
├── Prefabs/
├── Resources/
└── UI/
```

## 기대 효과

* 타로 카드 해석을 쉽고 재미있게 경험할 수 있음
* Unity 기반 애플리케이션 개발 학습
* 사용자 친화적인 상담형 인터페이스 제공
